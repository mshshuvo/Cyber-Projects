# Cyber-Projects

A 14-day series of small, practical cybersecurity and IT risk projects — one per day.

Each project lives in its own dated folder with:
- runnable code (mostly Python, standard library where possible)
- sample data
- a README covering the problem, how to run it, and how it maps to real GRC / security work (ISO/IEC 27001, NIST CSF, AML/KYC, etc.)
- a short LinkedIn post draft
